## 🔧 Технические детали

### Ключевые файлы:

**Frontend:**
- `resources/js/shared/composables/useCart.js` - логика корзины
- `resources/js/widgets/cart/Cart.vue` - страница корзины
- `resources/js/widgets/product/calculators/components/CalculatorAction.vue` - кнопки действий
- `resources/js/widgets/product/calculators/Calc146.vue` - калькулятор (пример интеграции)
- `resources/views/components/layout/header.blade.php` - header с badge

**Backend:**
- `backend/api/index.php` - роутер API
- `backend/api/src/MockData.php` - mock данные (и прокси к real API)
- `backend/api/src/ApiClient.php` - Guzzle HTTP клиент для real API

**Tests:**
- `backend/tests/html-test-runner.html` - браузерный test runner
- `backend/tests/cart-api-tests.js` - тесты API корзины

### localStorage структура:

```javascript
// psp_cart_items
[
  {
    id: "item_1234567890_abc123",      // frontend ID
    calc_position_id: 12345,            // API ID
    calculator_id: 146,                 // тип калькулятора
    price_good: 25000,                  // цена из API
    quantity: 2,                        // количество
    description: "Объемные буквы...",   // описание
    params: [...],                      // параметры для "Изменить"
    mat_select_params: [],              // материалы
    image: "/img/path/to/image.jpg"     // изображение
  }
]

// psp_calc_id
"42"  // ID текущего заказа в API
```
