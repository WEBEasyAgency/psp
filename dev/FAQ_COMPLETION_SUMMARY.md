## Как использовать

### 1. Просмотр результата

```bash
cd F:\CODE\easy_web\psp\dev
npm run build      # Собрать проект
# Затем откройте dist/product.html в браузере
```

### 2. Редактирование FAQ

Отредактируйте `product.html` (строки 269-456):
- Измените вопросы в `<summary>`
- Измените ответы в `<div class="faq-answer">`
- Скопируйте блок `<details>` для добавления новых элементов

### 3. Изменение стилей

Отредактируйте `<style>` в `<head>` файла `product.html`:
```css
/* Например, изменить цвет */
.product-faq details[open] .faq-icon {
  background-color: #YOUR_COLOR !important;
}
```

### 4. Добавление JavaScript функциональности (опционально)

Используйте `faq-enhanced.js` для:
- Только одного открытого элемента
- Аналитики
- Программного управления состоянием

## Проблемы и решения

### ❓ Вопрос: Как закрыть все FAQ при открытии нового?
**Ответ**: Используйте `faq-enhanced.js` с опцией `singleOpen: true`

### ❓ Вопрос: Как добавить новый FAQ элемент?
**Ответ**: Скопируйте блок `<details>...</details>` и измените текст

### ❓ Вопрос: Почему FAQ не работает на IE 11?
**Ответ**: IE 11 не поддерживает `<details>`. Используйте полифилл или переделайте на дивы

### ❓ Вопрос: Как отследить клики на FAQ в Google Analytics?
**Ответ**: Подключите `faq-enhanced.js` с `trackAnalytics: true`
