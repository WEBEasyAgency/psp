## Технические детали

### Структура HTML
```html
<div class="tabs-body">
    <div class="tab active" id="case1">
        <div class="cases-slider">
            <div class="swiper-wrapper">
                <div class="swiper-slide">
                    <div class="img">
                        <img src="/img/..." alt="...">
                    </div>
                </div>
                <!-- Повторить для каждого изображения -->
            </div>
        </div>
    </div>
    <!-- Повторить для case2, case3, case4 -->
</div>
```

### JavaScript инициализация
Слайдер инициализируется в `/layout/js/app.min.js` с использованием Swiper.js.

### CSS классы
- `.cases-slider` - контейнер слайдера
- `.swiper-wrapper` - обёртка слайдов
- `.swiper-slide` - отдельный слайд
- `.img` - контейнер изображения

## Рекомендации по добавлению изображений

1. **Формат:** Используйте JPG для фотографий
2. **Размер:** Изображения должны быть высокого разрешения (обычно суффикс `_o.jpg` или `_4k.jpg`)
3. **Alt-теги:** Всегда указывайте описательные alt для доступности
4. **Пути:** Используйте абсолютные пути начиная с `/img/...`

**Пример добавления нового изображения:**
```html
<div class="swiper-slide">
    <div class="img">
        <img src="/img/Контент/Контент/[категория]/[файл].jpg" alt="Описание">
    </div>
</div>
```
