## Анализ единиц измерения по группам

### Группа 1: Объемные буквы (ID 146, 155)
**Характеристики:**
- Высота буквы: **см**
- Количество букв: **шт**
- Размеры рамы/подложки: **м**

**Используемые единицы:**
- `см` - для высоты букв
- `м` - для больших размеров (рама, подложка)
- `шт` - для подсчета

### Группа 2: Вывески среднего размера (ID 156, 157, 158)
**Характеристики:**
- Все вывески используют одинаковые единицы
- Размеры: **м** (метры)
- Количество: **шт**

**Используемые единицы:**
- `м` - для ширины и высоты
- `шт` - для подсчета

### Группа 3: Стенды и таблички малого размера (ID 159, 160, 161)
**Характеристики:**
- Размеры: **см** (сантиметры)
- Количество: **шт**

**Используемые единицы:**
- `см` - для ширины и высоты
- `шт` - для подсчета

### Группа 4: Стенд с карманами (ID 151)
**Характеристики:**
- Размеры стенда: **см**
- Количество карманов: **шт** (каждый тип кармана отдельным параметром)
- Количество стендов: **шт**

**Используемые единицы:**
- `см` - для основных размеров
- `шт` - для подсчета (карманов и стендов)

### Группа 5: Наклейки (ID 154)
**Характеристики:**
- Размеры: **мм** (миллиметры) - единственный параметр с мм
- Количество: **шт**

**Используемые единицы:**
- `мм` - для ширины и высоты
- `шт` - для подсчета

## Сводка по используемым единицам

| Единица | Применяется в | Примеры |
|---|---|---|
| **см** | Небольшие изделия (буквы, таблички, стенды) | ID 146, 155, 151, 159, 160, 161 |
| **м** | Крупные вывески и конструкции | ID 146, 155, 156, 157, 158 |
| **мм** | Наклейки (мелкие изделия) | ID 154 |
| **шт** | Количество (универсальное) | Все калькуляторы |

## Общие закономерности

1. **Масштабирование по размеру:**
   - Объемные буквы: см для букв, м для конструкций
   - Средние вывески: м
   - Таблички и стенды: см
   - Наклейки: мм

2. **Единица "шт" (штуки):**
   - Используется для всех параметров количества
   - Применяется также для подсчета карманов, отверстий и дополнительных элементов

3. **Соответствие типам материалов:**
   - Пластиковые изделия: см или м в зависимости от размера
   - Акриловые изделия: см или м в зависимости от размера
   - Композитные изделия: м для вывесок, см для табличек

## Рекомендации для коррекции

### Потенциальные несоответствия:

1. **Калькулятор 146 и 155** - Смешанные единицы (см и м):
   - `rama_w` использует метры для рамы, но `sr_h` использует сантиметры
   - Рекомендация: Привести к одной системе (либо см, либо м)

2. **Калькулятор 154** - Единственный с мм:
   - Может быть несогласованность с общей шкалой
   - Рекомендация: Проверить, нужны ли мм или можно перейти на см

### Предлагаемая унификация:

```
Для вывесок и больших конструкций: метры (м)
Для табличек, стендов, букв: сантиметры (см)
Для наклеек: миллиметры (мм)
Для количества: штуки (шт)
```
